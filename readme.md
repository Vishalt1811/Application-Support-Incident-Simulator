# Application Support Incident Simulator

A hands-on Application Support project demonstrating SQL investigation,
Python troubleshooting, application log analysis, incident management,
root cause analysis, and responsible use of AI troubleshooting tools.

## Technologies

- Python
- SQL
- SQLite
- Git
- GitHub
- Linux/Command Line
- Application Logs
- ITIL Incident Management

## Project Goal

Simulate real-world production application incidents and investigate
them using logs, SQL queries, application code, and data analysis.
